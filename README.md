# Route Ready — U.S. Highway Quiz

A static, responsive quiz website built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Deploy to GitHub Pages
1. Create a GitHub repository (for example, `highway-route-quiz`).
2. Upload `index.html` and `highway-map.png` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published Pages URL after deployment finishes.

The map image is included in this project. Keep it in the same folder as `index.html`.
